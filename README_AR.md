# مساحة رغد — رسائل مجهولة

موقع عربي بتصميم رومانسي لاستقبال الرسائل المجهولة، مع صندوق خاص محمي بكلمة مرور لإدارة الرسائل. لا يستخدم الموقع أي خدمة ذكاء اصطناعي ولا يطلب من المرسل اسمًا أو حسابًا.

## الموجود في المشروع

- صفحة عامة ثابتة على المسار `/raghad`، جاهزة للمشاركة في حالة واتساب.
- نموذج رسائل مع أنواع اختيارية: من القلب، اعتراف، اشتياق ولهفة، كلمة حلوة، عتاب بلطف، شيء لم أقله.
- قاعدة بيانات تحفظ الرسائل؛ SQLite للتجربة المحلية وPostgreSQL للنشر.
- صندوق خاص على `/inbox` بكلمة مرور طويلة، مع قراءة الرسائل وتصفيتها وتحديدها كمقروءة وحذفها وتصديرها CSV.
- حد بسيط لمعدل الإرسال من الاتصال، وحد أعلى لطول الرسالة.
- الواجهة لا تطلب اسم المرسل ولا تحفظ عنوان IP داخل جدول الرسائل. نظام الاستضافة نفسه قد يعالج بيانات اتصال تقنية.

## 1. تشغيل محلي على الكمبيوتر أو Termux

تحتاج Python 3.11 أو أحدث وGit. افتح مجلد المشروع ثم نفّذ:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements-termux.txt
cp .env.example .env
```

افتح ملف `.env` بمحرر نصوص، واستبدل القيمتين `ADMIN_PASSWORD` و`SESSION_SECRET` بقيم خاصة بك. اجعل كلمة مرور الصندوق 12 حرفًا على الأقل، واجعل السر 32 حرفًا على الأقل. لا ترفع ملف `.env` إلى GitHub.

يمكن إنشاء سر عشوائي بهذا الأمر:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

انسخ الناتج إلى `SESSION_SECRET` داخل `.env`. ثم شغّل:

```bash
uvicorn app:app --host 127.0.0.1 --port 8000
```

افتح في المتصفح:

- الموقع العام: `http://127.0.0.1:8000/raghad`
- صندوق الرسائل: `http://127.0.0.1:8000/inbox`

التشغيل المحلي للتجربة فقط؛ لن تصل الرسائل من هاتف آخر إلا بعد نشر الموقع على الإنترنت.

## 2. رفع المشروع من Termux إلى GitHub

1. فكّ ضغط المشروع في مجلد واضح على الهاتف.
2. افتح Termux وانتقل إلى مجلد المشروع. مثال إذا كان داخل مجلد التنزيلات:

```bash
termux-setup-storage
cd ~/storage/downloads/raghad-lahfah
pkg update -y
pkg install git python -y
```

إذا فككت الضغط في مكان آخر، عدّل مسار `cd` حسب مكان المجلد.

3. عيّن اسمك وبريد Git الذي يستخدمهما سجل الالتزامات (استخدم بريد GitHub إذا رغبت):

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

4. أنشئ مستودعًا جديدًا فارغًا في GitHub من المتصفح. لا تضف README أو ملفات مسبقًا إلى المستودع الجديد.
5. شغّل سكربت الرفع:

```bash
bash push_to_github.sh
```

عندما يطلب رابط المستودع، الصق رابط HTTPS أو SSH الذي يعطيك إياه GitHub. إذا طلب GitHub كلمة مرور عبر HTTPS، لا تستخدم كلمة مرور حسابك؛ استخدم تسجيل الدخول أو Personal Access Token. تأكد أن `.env` غير موجود ضمن الملفات التي سترفعها.

يمكنك أيضًا تنفيذ الرفع يدويًا بعد إنشاء المستودع:

```bash
git init
git branch -M main
git add .
git commit -m "Build Raghad anonymous letters website"
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

استبدل `USERNAME/REPOSITORY` بالرابط الفعلي من حسابك، ولا تكرر `git remote add origin` إذا كان `origin` موجودًا بالفعل.

## 3. نشر الموقع حتى يصبح له رابط عام

رفع الملفات إلى GitHub وحده لا يجعل الموقع متاحًا للناس. يحتاج المشروع إلى استضافة وقاعدة بيانات.

### قاعدة البيانات الدائمة

أنشئ PostgreSQL على مزود قاعدة بيانات مثل Neon، ثم انسخ **Connection string** الخاص بـ PostgreSQL من لوحة المزود. احتفظ بالرابط سرًا لأنه يحتوي بيانات دخول قاعدة البيانات. خطط الخدمة المجانية قد تتغير أو تتوقف مؤقتًا عند الخمول، لذلك راجع شروط المزود قبل الاعتماد على الخدمة.

### النشر عبر Render

1. افتح Render واربط حسابك بمستودع GitHub.
2. اختر إنشاء Web Service من المستودع `raghad-lahfah`. إذا قرأ Render ملف `render.yaml`، أكمل إعداد المتغيرات المطلوب إدخالها.
3. استخدم أوامر البناء والتشغيل التالية إن طلبها يدويًا:
   - Build command: `pip install -r requirements.txt`
   - Start command: `uvicorn app:app --host 0.0.0.0 --port $PORT`
4. في Environment أضف:
   - `ADMIN_PASSWORD`: كلمة مرور طويلة وخاصة لصندوق رغد (12 حرفًا على الأقل).
   - `SESSION_SECRET`: سر عشوائي لا يقل عن 32 حرفًا؛ لا تستخدم مثالًا منشورًا.
   - `DATABASE_URL`: رابط PostgreSQL الذي نسخته من مزود قاعدة البيانات.
5. أكمل النشر وانتظر الحالة Live. سيعطيك Render نطاقًا عامًا شبيهًا بـ `https://اسم-خدمتك.onrender.com`.

الرابط الذي تشاركه مع رغد سيكون:

```text
https://YOUR-SERVICE.onrender.com/raghad
```

واستبدل `YOUR-SERVICE` بالنطاق الحقيقي الذي يعطيك إياه Render. صندوق الإدارة موجود في:

```text
https://YOUR-SERVICE.onrender.com/inbox
```

لا تشارك رابط الصندوق الخاص أو كلمة مروره مع الآخرين.

**تنبيه للاستضافة المجانية:** قد يتوقف خادم الويب عند الخمول ويحتاج وقتًا ليستيقظ عند أول زيارة. تأكد أن `DATABASE_URL` يشير إلى قاعدة PostgreSQL خارجية دائمة، لأن ملفات SQLite المحلية لا تكون تخزينًا دائمًا على خدمة ويب مجانية ذات نظام ملفات مؤقت. قاعدة PostgreSQL المجانية لها حدود وشروط يحددها مزودها.

## ملاحظات مهمة

- رابط رغد ثابت داخل الموقع: `/raghad`. لا تحتاج رغد لإنشاء رابط بنفسها.
- الرسائل مجهولة بالنسبة لصاحبة الصندوق، لكن لا يوجد موقع يستطيع أن يَعِد بإخفاء كل البيانات التقنية عن مزود الاستضافة أو الشبكة. لا ترسل معلومات شديدة الحساسية.
- كلمة المرور لا تُخزّن في GitHub، بل في متغيرات البيئة لدى الخادم.
- هذا مشروع بداية عملي وقابل للتوسعة. اختبر الإرسال والدخول والحذف والتصدير قبل نشر الرابط علنًا.
